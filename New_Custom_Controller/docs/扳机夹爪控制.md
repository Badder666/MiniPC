# RC8P 扳机控制夹爪

CH1 脉宽由控制器经 USB 上报，小电脑通过 ROS2 转发到机械臂下位机。
上位机不下发控制器的重力补偿力矩，控制器继续使用 MCU 本地补偿。

| 扳机操作 | CH1 脉宽 | 夹爪行为 |
| --- | --- | --- |
| 中位 | 1500±30 μs | 保持当前目标位置 |
| 向下扣动 | 向1916 μs增大 | 关闭，偏离中位越大速度越快 |
| 向上反推 | 向1084 μs减小 | 打开，偏离中位越大速度越快 |

满行程默认目标速度为150°/s，夹爪目标范围沿用下位机的-21°～133.8°。
扳机失效后不再累计位置增量。原有遥控器控制和面板btn4开合切换保留。
夹爪仍需满足原有机械臂使能条件并收到电机反馈。

## 构建与启动

先分别编译、烧录两块板，使用本次生成的文件：

- 控制器：`Custom_Controller/cmake-build-debug/Custom_Controller.elf` 或 `.hex`。
- 机械臂：`Engineer_2026_H7_Template_new/cmake-build-debug/Engineer_2026_H7_Template_new.elf` 或 `.hex`。

两块板的协议字段均有更新，需要一起烧录。将两路 USB 连接到 Ubuntu 虚拟机。
在 Ubuntu 工作区执行：

```bash
cd /home/badder/minipc/New_Custom_Controller
source /opt/ros/humble/setup.bash
colcon build --packages-select custom_controller_interfaces custom_controller_usb --symlink-install
source install/setup.bash
ros2 launch custom_controller_usb teleop_visualization.launch.py
```

也可使用桌面的“控制器可视化与机械臂遥操”快捷方式。串口通过现有USB序列号区分两块板，
该入口保持`gravity_feedforward=false`。

## 检查与调参

```bash
source /opt/ros/humble/setup.bash
source /home/badder/minipc/New_Custom_Controller/install/setup.bash
ros2 topic echo /custom_controller/state
```

确认`trigger_valid: true`，操作扳机时`trigger_us`在约1084～1916之间变化。
板端 Monitor 可观察`MiniPC_Data.trigger_us`、`MiniPC_Data.trigger_valid`，以及
`M2006_Gripper_Motor.Data.Target_Angle`和`M2006_Gripper_Motor.Data.Angle`。

机械臂工程`Config/arm_config.h`的`GRIPPER_TRIGGER_*`宏可调整中位、死区、端点、
最大速度和方向。`GRIPPER_TRIGGER_MAX_SPEED`单位为°/s；修改后重新编译烧录机械臂。
