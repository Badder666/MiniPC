# J3 提前反向分析

2026-10-07，使用虚拟机当前运行的 URDF2 模型进行离线检查；没有修改模型或启用力矩输出。
计算条件：q1=q2=q4=q5=q6=0，仅变化 q3；模型重力为 [0, 0, -9.7883]。
这里 q 是映射后 URDF 关节角，不是电机原始编码值。实机其他关节姿态不同时，以下数值会变化。

## 模型过零原因

link3 到 link6 的总质量为 1.242951585 kg，质量加权的总质心相对 J3 关节坐标系为：

```text
X = +124.729 mm
Y =  -54.285 mm
Z =  -15.462 mm
```

J3 的 axis 是局部 -Z，局部 XY 是旋转平面。局部 Y 的约 -54.3 mm 侧向偏移
使总质心不在主体连杆方向的射线上；不能用主体连杆竖直来直接推断重力矩等于零。
在本次固定其他关节的姿态下，重力支撑力矩近似为：

```text
tau3(q3) = 1.517502 * cos(q3) - 0.660453 * sin(q3)  [Nm]
```

因此过零约为 atan2(1.517502, 0.660453) = 66.5 度。
q3=90 度时模型力矩为 -0.660453 Nm；统一比例 0.75 后下发值为约 -0.495340 Nm。
这个推导解释当前模型的输出，不能验证 CAD 质量、质心或实物零位正确。

link3 的自身质心局部 Y=-53.45 mm；在本次姿态中 link4/link5 的质心换算到 J3 坐标系后
局部 Y 约为 -60 mm。该偏移来自 URDF 关节几何和连杆惯性原点的组合，不是 Pinocchio
对 90 度的特殊处理，也不是统一补偿比例造成的。

## 待实物验证的项目

1. 保持 J2 和后三轴在同一组已知姿态，比较实物 J3=0、90 度时的整体方向与 RViz。
2. 对照 CAD/实物，核查 J3 后方机构的横向台阶、质心和转轴相对位置；侧向偏移是否确实约 54 mm。
3. 若实物质量分布不符，应修改对应 link 的 inertial/origin xyz、mass 或修正几何定义。
4. 若模型转动姿态与实物不符，应校正角度映射/offset；不能只为让力矩在 90 度过零而添加角度偏置。

link/inertial/origin xyz 表示连杆质心相对该 link 坐标系的位置；joint/origin xyz 表示转轴中心
相对父 link 的位置。这两种 xyz 不同，修改任意一种都可能改变重力力臂。
没有实物测量或同姿态力矩数据时，不能给出可信的质心/旋转中心修正量。
