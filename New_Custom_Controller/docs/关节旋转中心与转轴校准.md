# 关节旋转中心与转轴校准

RViz 的 `Joint Centers + Rotation Axes` 显示六轴中心球、编号及转轴箭头。
橙色 `J1 LIVE` 到 `J6 LIVE` 对应灰色实时模型，绿色 `J1 ZERO` 到 `J6 ZERO` 对应 offset 零点参考模型。
球心为 URDF 关节原点，箭头指向 axis 定义的正转方向。
RViz 的该显示项下可以分别勾选 `joint_centers_live`、`joint_centers_zero`，减少重叠。
本次仅增加标记，没有调整模型几何参数。

## 修改哪个参数

运行模型路径为：

```text
/home/badder/minipc/New_Custom_Controller/src/custom_controller_usb/config/controller_model_urdf2/controller.urdf
```

修改关节 `<joint name="jointN">` 内的 `<origin xyz="x y z" rpy="roll pitch yaw"/>`。

- `xyz` 是旋转中心相对父连杆坐标系的位置，单位米；0.001 m = 1 mm。
- `rpy` 是关节零位坐标系相对父连杆的方向，单位弧度。
- `<axis xyz="..."/>` 是关节坐标系里的转轴方向，单位向量。
- YAML 的 `offsets` 是关节角度偏置，单位弧度，用于校准编码器零点，不是中心位置平移。

URDF2 六轴当前几何定义：

| 关节 | 父连杆坐标系 | origin xyz，米 | 同一 xyz，毫米 | origin rpy，弧度 |
|---|---|---|---|---|
| J1 | base_link | 0, 0.006, 0 | 0, 6, 0 | 1.5708, 0, 0 |
| J2 | link1 | 0.0064705, 0.024148, 0.051 | 6.4705, 24.148, 51 | -1.5708, 0, -0.2618 |
| J3 | link2 | -0.13, 0, -0.0045 | -130, 0, -4.5 | 0, 0, 0 |
| J4 | link3 | 0.062989, -0.06, -0.0345 | 62.989, -60, -34.5 | 1.5709, -1.5708, 1.5707 |
| J5 | link4 | 0.0462, 0, 0.047011 | 46.2, 0, 47.011 | 1.5678, -1.5708, -1.5676 |
| J6 | link5 | 0.1335, 0, 0.0462 | 133.5, 0, 46.2 | 1.5585, 1.5708, 1.5585 |

六轴 `axis xyz` 均为 `0 0 -1`。上表不是 world 坐标，父连杆转动时中心在 world 中也会移动。
新增的固定关节 `controller_mount_to_base` 用于底座安装坐标变换，不能当成某个电机关节的中心偏置。

## 示例：J3 中心沿父连杆 X 移动 5 mm

找到 joint3 当前定义：

```xml
<origin xyz="-0.13 0 -0.0045" rpy="0 0 0" />
```

把 x 增加 0.005，得到：

```xml
<origin xyz="-0.125 0 -0.0045" rpy="0 0 0" />
```

这是修改方法示例，不是实物测得的推荐值。可用 `xyz_new = xyz_old + delta_xyz` 调整其他关节。
沿轴线移动原点不一定改变转轴线；垂直于轴线的位移才会使转轴线横向移动。
修改 joint origin 会连同子连杆和后续关节一起移动，也会改变重力力臂。
如果只是重新定义 CAD 坐标系、希望机构几何不变，还需要一致地更新相关网格、质心及关节坐标变换。

offset 改变的是绕转轴的零点角度，不会移动该关节本身的中心，但会带动后续关节中心。
同一关节单独转动时，其中心应固定在父连杆上；可据此比较标记与实际轴承/输出轴中心。
仅凭补偿效果无法确定 xyz 的修正量，应以实物尺寸或 CAD 中实际转轴位置为依据。

## 生效方法

```bash
nano ~/minipc/New_Custom_Controller/src/custom_controller_usb/config/controller_model_urdf2/controller.urdf
```

修改后重新启动 launch。当前使用 symlink-install，修改已安装的 URDF 文件不需要重新编译。
校准模式的停止、启动命令见 `RViz关节零点校准.md`；模型几何修改会同时影响后续启动的 Pinocchio。
