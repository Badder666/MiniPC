# 自定义控制器下发协议

上位机通过 USB CDC 接收自定义控制器的 104 字节、25 通道 JustFloat 状态帧，再通过另一个串口向机械臂下位机发送 64 字节命令帧。旧42字节二进制状态帧仍可接收，但不包含扳机信息。USB CDC 是字节流，接收端必须允许拆包和粘包。

## 64 字节命令帧

所有多字节字段均为小端序，CRC 使用 CRC-16/MCRF4XX，初值 `0xffff`，覆盖偏移 `0..61`，低字节在前。

| 偏移 | 长度 | 内容 |
| ---: | ---: | --- |
| 0 | 2 | 帧头 `A5 5A` |
| 2 | 1 | 版本 `1` |
| 3 | 1 | 类型 `0x10` |
| 4 | 2 | 总长度 `64` |
| 6 | 2 | 上位机序号 |
| 8 | 4 | 控制器时间，毫秒 |
| 12 | 24 | 六轴目标位置，`float32`，弧度 |
| 36 | 2 | 控制器按键位图 |
| 38 | 2 | 有效关节位图，bit 0 到 bit 5 对应 J1 到 J6 |
| 40 | 2 | 摇杆 X，0 到 4095 |
| 42 | 2 | 摇杆 Y，0 到 4095 |
| 44 | 6 | 鼠标 X/Y/Z，三个 `int16` |
| 50 | 3 | 鼠标左/右/中键，沿用旧协议的 0 到 3 |
| 53 | 1 | 标志，bit 0 表示键鼠摇杆有效，bit 1 表示扳机有效；其他位为0 |
| 54 | 4 | 键盘位图，bit 0 到 bit 17 为 W、S、A、D、Shift、Ctrl、Q、E、R、F、G、Z、X、C、V、B、1、2 |
| 58 | 1 | 旧协议 `main_buttons` |
| 59 | 1 | 旧协议 `handle_buttons` |
| 60 | 2 | CH1 扳机脉宽，`uint16`，μs；无效时必须为0 |
| 62 | 2 | CRC16 |

默认电机 1 到 6 对应机械臂 J1 到 J6，方向比例为 `[-1, -1, +1, -1, -1, +1]`，其中 J3 使用 `+1` 以匹配实际控制器方向；零位偏置为 `[0, 2.4, -2.4, 0, 0, 0]`，控制器全零对应机械臂折叠姿态。上位机在每次控制器状态回调中构建帧，下位机只更新有效位对应的关节。状态上报停止后桥接不重复生成旧目标帧；没有新增通讯超时关闭电机逻辑，原有下位机在线状态检测保持原行为。

序号是上位机独立计数器，每次成功编码命令后递增，按 `2^16` 回绕；丢弃待发送帧、串口断开都可能产生跳号。时间戳仍是控制器采集时间，按 `2^32` 毫秒回绕。

`buttons` 始终保留控制器原始 16 位。映射通过 `command_bridge.yaml` 的源位索引配置，结果再与外部操作输入的面板状态按位或。接线未确定，因此源位默认全部为 `-1`，表示禁用动作映射。例如把 `handle_button_bits[3]` 设为 11，可将控制器 bit 11 映射到原下位机 `btn4` 夹爪功能。

bit 0 操作有效标志为 0 时，下位机清零键鼠与面板字段，并将摇杆设为 2048。该标志不影响六轴有效位及原始按键字段。

JustFloat 通道20为 CH1 脉宽，通道21为有效标志。有效标志必须为1且脉宽为700～2300的整数才转发；否则发送脉宽0并清除命令标志bit1。机械臂下位机也执行相同校验。
扳机输入独立于键鼠摇杆有效标志。夹爪的中位、死区和速度由下位机计算，操作见[扳机夹爪控制](扳机夹爪控制.md)。

## ROS2 运行

`usb_receiver.launch.py` 同时启动状态接收节点和下发节点：

```bash
ros2 launch custom_controller_usb usb_receiver.launch.py \
  port:=/dev/ttyACM0 command_port:=/dev/ttyACM1
```

键鼠/摇杆程序向 `/custom_controller/operator_input` 发布 `OperatorInput`。没有发布时使用摇杆中位、鼠标释放和键盘清零。

旧工程的操作话题可通过 `legacy_input:=true` 启用适配，需先 source 旧 `NEW_test_6_15` 的安装环境；适配 `/tc_info` 键鼠和 `/ccctrl_positions` 中的摇杆、面板字段。默认不启动这个可选节点。

下位机接收路径是 `CDC_Receive_HS → USBComm_PushFromISR → MiniPC_Receive_Info → ControllerStream_Feed`。USB 初始化及反初始化重置接收状态，缓冲溢出时丢弃破损片段并重新寻找帧头。新协议与旧 60 字节 `AA...55` 命令均可接收。

机械臂反馈继续使用原 27 字节格式：`AA + 六个 float32 弧度位置 + 数据字节累加和 + 55`。上位机发布 `/custom_controller/arm_joint_states`，与控制器的原始 `/custom_controller/joint_states` 分开。
