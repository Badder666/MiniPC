# 启动可视化与机械臂遥操

Ubuntu 虚拟机桌面的 **控制器可视化与机械臂遥操** 快捷方式会同时启动：

- 控制器 USB 反馈接收和控制器 RViz。
- 机械臂 USB 命令转发、反馈接收和机械臂 RViz。

轨迹采集、轨迹显示和质心显示默认关闭。重力补偿在 MCU 内运行，
本启动方式不下发上位机重力力矩；需要上下位机对照时，可停止后使用原来的
`identified_gravity.launch.py gravity_dry_run:=false torque_scale:=1.0`。

## 使用方式

1. 将控制器和被控机械臂的 USB 都连接到 Ubuntu 虚拟机。
2. 双击桌面快捷方式。终端显示运行日志，两个 RViz 窗口分别显示控制器与机械臂。
3. 在启动终端按 **Ctrl+C** 停止上位机显示和遥操转发。

停止上位机程序不会停止 MCU 的本地重力补偿，也不会关闭电机使能。
重复启动会被拦截，避免多个程序同时打开同一串口。
如果正在运行旧启动命令，应先在旧终端停止，再使用桌面快捷方式。
USB 未连接时程序会显示等待/重连日志；连接设备后自动重试。

## 串口与映射

使用设备标识固定串口角色，避免 ttyACM0/ttyACM1 顺序变化：

```text
控制器：/dev/serial/by-id/usb-STMicroelectronics_STM32_Virtual_ComPort_313F36753233-if00
机械臂：/dev/serial/by-id/usb-STMicroelectronics_STM32_Virtual_ComPort_326433533034-if00
```

遥操映射由虚拟机工程的 `src/custom_controller_usb/config/command_bridge.yaml` 管理。
控制器显示映射由 `src/custom_controller_usb/config/controller_mapping_urdf2.yaml` 管理。
两份配置具有不同用途；零位或方向修改后重启快捷方式生效。
控制器重力模型零位还需与 MCU 的 `Device/controller_calibration.c` 保持一致。

## 终端启动与编译

```bash
cd ~/minipc/New_Custom_Controller
bash tools/start_teleop_visualization.sh
```

修改 Python 或 launch 后编译：

```bash
cd ~/minipc/New_Custom_Controller
source /opt/ros/humble/setup.bash
colcon build --packages-select custom_controller_usb --symlink-install
```

快捷方式每次自动加载 ROS2 和当前工作区，无需手动 source。
