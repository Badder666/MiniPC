# 控制器物理仿真

本阶段实现控制器模型、重力补偿和模拟人手外力，尚未加入导纳或外力矩观测器。
程序独立于 ROS2，不打开串口、不读取真实控制器，也不向任何电机发送指令。

## 启动

在 Ubuntu 虚拟机终端运行：

```bash
cd ~/minipc/New_Custom_Controller
bash tools/start_controller_sim.sh
```

也可以双击 Ubuntu 桌面的 **控制器 MuJoCo 仿真**。
启动入口使用 `~/venvs/controller_sim`，无需手动激活 Python 环境。
第一次运行通过 gcc 编译纯 C 重力算法，动态库缓存到 `~/.cache/custom_controller_sim`。

## 施加人手外力

先点击 MuJoCo 窗口让键盘焦点进入，再操作以下按键：

| 操作 | 效果 |
| --- | --- |
| U | 在 link6 橙色标记处向世界 +Z 施加 0.5 N，持续 0.3 s |
| J | 在同一点向世界 -Z 施力 |
| I | 在同一点向世界 +Y 施力 |
| K | 在同一点向世界 -Y 施力 |
| G | 开关重力补偿；关闭时速度阻尼仍保留 |
| R | 返回初始姿态并清除速度与外力；不改变补偿开关 |
| P | 暂停或继续仿真 |

鼠标可施加连续外力：双击选中活动 Link，然后按住 Ctrl 和右键拖动；
Ctrl 和左键拖动可施加旋转力矩。选中固定的底座不会使底座移动。
按键外力作用于 link6 坐标原点，并随着末端移动；力方向使用世界坐标。
鼠标外力可作用于选中的其他活动 Link。

初次观察可按一次 U 或 I，再按 R 重置，比较 G 开关前后的表现。
终端每秒显示当前关节位置、重力前馈及真实外部广义力矩。
这里的 external 是仿真引擎中的已知输入，用于后续验证观测器，不是电机反馈力矩。

## 参数

默认使用：

- 初始 URDF 角度 `[0, -0.8, 1.1, 0, 0, 0]` rad，仅为仿真初始姿态。
- 物理步长 1 ms，重力前馈每 10 ms 更新，比例为 1。
- 速度阻尼 `[0, 0.3, 0.3, 0, 0, 0]`，与当前 MCU 参数一致。
- 理想电机力矩为 `重力前馈 - KD × 速度`，位置刚度为零。

J1/J4/J5/J6 默认没有阻尼，受力后的运动不会立即停止。
如果希望先观察六轴都有阻尼的响应，可以另开以下仿真参数：

```bash
bash tools/start_controller_sim.sh --damping 0.05,0.3,0.3,0.05,0.05,0.05
```

修改仿真参数不会修改 MCU 固件。
自定义外力大小或初始姿态：

```bash
bash tools/start_controller_sim.sh --hand-force 0.2 --pulse-duration 0.2
bash tools/start_controller_sim.sh --initial=0,-0.6,0.8,0,0,0
```

## 导出数据

```bash
bash tools/start_controller_sim.sh --csv /tmp/controller_sim.csv
```

CSV 每 10 ms 记录仿真时间、六轴位置/速度、重力前馈、电机驱动力矩、
外部广义力矩和按键/脚本施加的三维力。程序拒绝覆盖已有 CSV。
六轴角度和力矩均为 URDF 坐标，并非原始电机编码坐标；
不要直接复用实机的经验性力矩输出方向，将它们再乘到 MuJoCo 关节力矩上。

无窗口可重复施力试验：

```bash
bash tools/start_controller_sim.sh --headless --duration 3 \
  --force 0,0,0.5 --force-start 1 --force-duration 0.3 \
  --csv /tmp/controller_force_test.csv
```

## 模型与适用范围

使用 `controller_identified.urdf`，保留安装变换及辨识后的质量和质心。
`gravity_c` 保存当前 MCU 的四个 Algorithm 源文件快照，直接编译调用，
模型输入输出与 Pinocchio 的 URDF 关节坐标保持一致。
只对导入副本转换网格路径并将六个关节设为 continuous，原 URDF 不修改。
关节没有固定角度限位，STL 仅用于显示，所有接触碰撞关闭。
因此本阶段不能用于判定机构碰撞或生成安全采样路径。

惯量使用原 URDF 数值，没有通过静态质心数据重新辨识。
电机目前采用理想力矩执行，尚未模拟摩擦、电机电流环、减速器惯量或 CAN 延迟。
重力函数为单精度 C 运算，而 MuJoCo 动力学采用双精度，未加阻尼的轴可能出现小幅数值漂移。
以后添加观测器时，应独立设置模型误差与噪声，不能把本阶段理想模型的效果等同于实机效果。

## 验证

1000 个随机姿态下，MCU 同源算法与 MuJoCo 零速度重力力矩最大差约 `1.0e-6 N·m`。
默认初始姿态静止仿真 1 s，最大位置偏移约 `6.4e-5 rad`。
末端施力、补偿关闭、重置和快捷键脉冲均已验证。
临时验证脚本与数据保存在工程外，不作为运行依赖。
